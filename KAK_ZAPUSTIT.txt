Как запустить RepairCalc на своём компьютере (Windows)
======================================================

1. Нужен Python 3.11 или новее.
   Проверить: в PowerShell  python --version
   Если нет: python.org -> Downloads -> Python 3.12, при установке галочка "Add python.exe to PATH".

2. Распакуй архив в папку без русских букв, например C:\repaircalc

3. В терминале VS Code (или PowerShell в этой папке):   .\start.bat
   Откроется http://localhost:8000. Остановить: Ctrl+C.

Настоящий каталог организаторов
-------------------------------
1. Положи файл каталога в папку data и назови  catalog.json
   (получится C:\repaircalc\data\catalog.json)
2. В терминале VS Code в папке проекта:
      .\start.bat --reload-data
   (первый раз он сам создаст .venv и поставит библиотеки)
   50 000 товаров грузятся примерно за 1-3 минуты. Чтобы взять только часть:
      $env:RC_LOCAL_LIMIT=5000
      .\start.bat --reload-data

Без файла data\catalog.json используется пример из 27 синтетических товаров.

Полезное
--------
http://localhost:8000/docs                       — все адреса API
.venv\Scripts\python.exe -m scripts.profile_characteristics  — какие характеристики есть в каталоге
.venv\Scripts\python.exe -m scripts.evaluate_matching        — micro-F1 / macro-F1 классификатора на эталоне

Через Docker (как будет на сдаче)
--------------------------------
1. Установи Docker Desktop (docker.com), при установке согласись на WSL 2, перезагрузи компьютер.
2. Запусти Docker Desktop и дождись, пока внизу будет "Engine running".
3. В терминале в папке проекта:
      docker compose up -d --build
      docker compose run --rm ingest
   Первая команда собирает и запускает сервер с базой PostgreSQL,
   вторая загружает data\catalog.json. Открывай http://localhost:8000
4. Остановить:  docker compose down
