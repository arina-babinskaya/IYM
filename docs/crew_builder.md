# Демонстрационный подбор бригады

Вкладка «Бригада» показывает, как рассчитанная в RepairCalc смета может быть связана с подбором исполнителей. Это только демонстрация: профили, имена, опыт, ставки и сроки вымышлены; бронирования, контактов и оплаты нет.

## Связь работ и профессий

Используется существующая `WorkType`-таксономия калькулятора:

| Профессия | Типы работ |
|---|---|
| Мастер демонтажных работ | `demolition` |
| Электрик | `electrical_wiring`, `electrical_fittings`, `lighting_install` |
| Сантехник | `plumbing_rough`, `plumbing_fixture_install` |
| Монтажник инженерных систем | `ventilation_install`, `heating_climate_install` |
| Мастер по гидроизоляции | `waterproofing` |
| Мастер по стяжке пола | `floor_screed` |
| Штукатур | `wall_plastering` |
| Монтажник гипсокартона | `drywall_install` |
| Маляр-отделочник | `wall_putty`, `priming`, `wall_painting`, `wallpapering` |
| Плиточник | `tiling` |
| Мастер по напольным покрытиям | `floor_covering_install` |
| Монтажник дверей и окон | `door_window_install` |
| Мастер декоративной отделки | `decorative_finish_install` |

Неизвестный будущий тип работы попадает к «Мастеру-универсалу». Совместимые работы объединяются в одну роль без дублей. Работы берутся из `room.works` ответа сметы; если поле отсутствует, используется список позиций сметы. Комнаты агрегируются в одну бригаду.

## Объём, срок и цена

Для каждой работы площадь пола или стен делится на фиксированную демонстрационную производительность в м² за человеко-день. Минимальный объём одной работы — 0,5 человеко-дня. Человеко-дни суммируются внутри профессии и не меняются при добавлении работников.

В каждой профессии можно выбрать от одного до трёх демонстрационных специалистов. Длительность профессии равна `ceil(человеко-дни / выбранные специалисты)`, но не менее одного рабочего дня. Общий расчётный срок — консервативная сумма длительностей всех профессий: демо не предполагает, что разные этапы всегда можно выполнять параллельно.

Нагрузка профессии поровну делится между выбранными специалистами. Базовая стоимость равна сумме `доля человеко-дней специалиста × его дневная ставка`. Поэтому дополнительный специалист сокращает срок, а цена может немного измениться из-за различия ставок, но один и тот же объём работ не умножается на количество работников. Если желаемый срок короче расчётного, сохраняется единый коэффициент срочности:

`min(1,5; 1 + (базовый срок − желаемый срок) / базовый срок × 0,75)`.

При сроке не короче расчётного коэффициент равен 1, поэтому растянутый календарный срок не увеличивает цену одинакового объёма работ. Срок считается достижимым выбранным составом, только если он не короче расчётного. Если работников ещё можно добавить, интерфейс предлагает это сделать. Срок короче суммы минимальных длительностей при трёх специалистах каждой профессии помечается как недостижимый даже максимальным демонстрационным составом. Значения меньше 1 и нецелые значения не принимаются.

## Состояние и ограничения

При новом расчёте роли пересобираются из свежей сметы. Все доступные выбранные специалисты сохраняются для оставшихся ролей, удаляются для исчезнувших, а для новой роли выбирается один демонстрационный кандидат. Снять последнего специалиста профессии нельзя. Состояние калькулятора не изменяется при переходах между вкладками. Материалы, ранжирование, каталог, классификаторы и консультант не затрагиваются.

Данные живут только во frontend-памяти и исчезают после перезагрузки страницы. Расчёт не является подрядной офертой, рыночной оценкой или календарным планом и не учитывает зависимости между этапами, выходные и логистику.
